# Flipkart Stock & Price Tracker Telegram Bot

একটি শক্তিশালী টেলিগ্রাম বট যা স্বয়ংক্রিয়ভাবে Flipkart-এর প্রোডাক্টগুলোর স্টক এবং দাম ট্র্যাক করে। কোনো প্রোডাক্ট স্টকে আসা মাত্র বা দাম কমা মাত্র টেলিগ্রামে তাৎক্ষণিক নোটিফিকেশন পাঠায়।

## 🚀 সেটআপ করার নিয়ম (How to Setup)

### ১. টেলিগ্রাম বট টোকেন তৈরি করুন
1. টেলিগ্রাম ওপেন করে সার্চ করুন `@BotFather`
2. BotFather-এ গিয়ে লিখুন: `/newbot`
3. বটের একটি নাম দিন এবং একটি ইউজারনেম দিন (যা `bot` দিয়ে শেষ হবে, যেমন: `my_flipkart_stock_bot`)
4. BotFather আপনাকে একটি **HTTP API Token** দেবে।

### ২. `.env` ফাইলে টোকেন বসান
`.env` ফাইলটি ওপেন করুন এবং টোকেনটি পেস্ট করুন:
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
DEFAULT_CHECK_INTERVAL=300
```

### ৩. বট রান করুন
টার্মিনালে গিয়ে নিচের কমান্ডটি রান করুন:
```bash
python bot.py
```

## 📱 টেলিগ্রাম বট কমান্ডস
- `/start` : বট শুরু করতে ও নির্দেশনা দেখতে
- `/seed` : **আইফোন ১৭ (২৫৬ জিবি)**-এর সবকটি কালার (White, Black, Mist Blue, Sage, Lavender) ১-ক্লিকে যোগ করতে
- `/add <Flipkart Link>` : যেকোনো নতুন ফ্লিপকার্ট প্রোডাক্ট লিংক যোগ করতে
- `/list` : ট্র্যাক করা সমস্ত পণ্যের বর্তমান দাম ও স্টক স্ট্যাটাস দেখতে
- `/check` : এখনই সমস্ত প্রোডাক্ট লাইভ চেক করতে
- `/remove <ID>` : কোনো প্রোডাক্ট ট্র্যাকিং বাদ দিতে
- `/interval <মিনিট>` : কত মিনিট পর পর অটো-চেক করবে নির্ধারণ করতে (যেমন: `/interval 5`)
